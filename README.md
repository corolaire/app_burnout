# 🧠 Detector de Burnout

App web interactiva que permite detectar el nivel de burnout de una persona en menos de un minuto.  
Desarrollada con **Python + Flask**, pensada para desarrolladores, freelancers o cualquier persona que sienta estrés sostenido.

---

## 🚀 ¿Qué hace?

✔️ Presenta preguntas simples sobre tu rutina y estado actual  
✔️ Calcula tu nivel de riesgo (bajo, medio o alto)  
✔️ Muestra un mensaje personalizado con consejos  
✔️ Envía el resultado por mail si ingresás tu correo
